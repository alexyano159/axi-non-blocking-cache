SHEET 1 · read-miss / write-back path
REV: sketch v1

Read-miss flow

  1. CPU load misses in the tag array.
  2. Controller → MSHR: requests a slot (alloc_valid/addr).
  3. MSHR: merges into an in-flight entry, or opens a free one (FE_IDLE→FE_REQ).
  4. Round-robin arbiter grants the shared AR channel to one waiting entry.
  5. AR/R burst: 4 beats stream back, tagged by rid, into that entry's buffer.
  6. MSHR → Controller: completed line handed off (fill_valid/fill_ready); entry frees the same cycle.
  7. Controller installs the line (evicting + writing back a dirty victim first, if the set was full).
